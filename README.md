npm install

Acceso inicial: admin / admin123

## Publicar en GitHub Pages

El repositorio incluye un flujo de GitHub Actions que compila y publica la aplicación
al subir cambios a `main`. En GitHub, configura **Settings > Pages > Build and
deployment > Source** como **GitHub Actions**. La aplicación estará disponible en
https://dakutito.github.io/EvaluadorDeTareas/.
